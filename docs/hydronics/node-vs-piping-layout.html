How the tabs use this information

System → Nodes

Create and name the dark-dot connection points. Choose which nodes are the pump discharge and suction.

Sections

Create each colored physical run once. Choose its From node and To node, then provide pipe and loss data.

Circuits

List the sections that form each terminal route. The engine derives the shared-section flow from all active terminal circuits.

How this relates to the legacy workbook

The workbook’s rows mostly describe sections (pipe and loss data), not named nodes. Its diagram suggests some connectivity but does not provide a complete, machine-readable list of connection points and circuit membership.

Therefore, the calculator’s generated workbook-reference nodes are placeholders. They should not be treated as actual field junction names. The provisional 100-GPM loader only joins the supported 07–31 route into a sequence; it does not claim to reconstruct every branch of the original system.

Practical rule of thumb

  1. Put a node anywhere flow can start, end, split, merge, enter equipment, or leave equipment.
  2. Put a section between two adjacent nodes when it has one coherent pipe/loss description.
  3. If the pipe size, length, roughness, or losses change materially, end one section at a node and start another section.
  4. Use a circuit only after you can state the complete supply → terminal → return route without guessing.
