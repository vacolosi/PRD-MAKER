## Architecture

Current source flow is:

```text
ProjectSlice (Zustand + immer + zundo)
  floors/rooms/zones/air systems + sparse ventilation/box edits
      -> V2 projection/command adapters
      -> V2VentilationDerived sizing results + box configuration overlay
      -> V2RiserDerived
      -> vent-calc extract -> deriveHw -> schematic layout -> SVG -> DXF
```

This flow has solid host seams for project/floor IDs, 2D calibrated plan coordinates, terminal-box placement, command routing, persistence, undo, and a deterministic SVG/DXF renderer. It does **not** have the required separate source flow:

```text
resolved hydronic criteria + explicit equipment/ports + authored supply/return graph
  + physical 3D route/length sources + reviewed terminal GPM/losses
      -> versioned PD adapter input -> qualified hydronic engine
      -> stale-aware results -> riser projection/export
```

The INT-01 contract should introduce that source flow as additive host data, not retrofit it into `ventilation`, airside `pressure-drop`, or the present `HwGraph`.

3. **Coordinate/Z/length contract.** Approve viewer-world feet/y-down → hydronic world-frame conversion at one boundary; define a building Z datum, floor registration behavior, physical centerline/end conventions, cross-floor vertical-leg representation, and whether diagonal 3D segments are allowed. Approve explicit `measured | declared | unresolved` length provenance and override semantics.
4. **Supported first topology/service scope.** Confirm closed-loop CHW/HW as separate systems, one pump discharge/suction boundary each, explicit supply + terminal + return sections, and rejection of mesh/bypass/primary-secondary cases. Confirm current generic top-fed HW riser is display-only legacy behavior, never a source fallback.
5. **BoD representation/review behavior.** Approve exact per-service project defaults plus per-system sparse overrides for engine fluid-reference IDs, supply/return/mean temperatures, pipe/roughness/fitting policies, and safety-factor acknowledgement/categories; decide whether existing vendor display strings can be retained only as UI metadata. 6. **Water-demand source policy.** Approve which upstream selected/reviewed coil data can populate `terminalDesignGpm`; explicitly disallow current airside calculated/reheat-riser GPM, rounded labels, CFM, and plant aggregate flow as a default source.
7. **Persistence/freshness partition.** Approve separate persisted authored network, criteria-resolution/review records, engine-result snapshot/input fingerprint, and cosmetic riser-layout state.
